# 权限与更新

## 更新

启动时会静默检查 GitHub Release，有新版本时弹窗：可以直接下载安装（会核对 SHA256SUMS.txt）、以后再说，或不再检查。设置里可以关闭自动检查、手动检查，或打开发布页。

## 权限说明

| 权限 | 用途 |
|---|---|
| 所有文件访问（Android 11+）/ 存储读写（Android 8–10） | 管理文件 |
| 读取已安装应用列表 | 「已安装应用」页面 |
| 网络 | 网络位置、连接电脑和云盘 |
| 相机 | 扫描电脑上的配对二维码 |
| 通知、前台服务 | 显示长时间复制、移动的进度 |
| 安装应用 | 点 APK 时交给系统安装器 |
| NFC（授权库声明） | 支持使用 NFC 安全密钥完成授权；不要求设备具备 NFC |

TwinFile 不包含统计和广告。开启自动更新检查时会访问 GitHub；下载更新 APK 时会访问 GitHub 的发布资源。网络位置、电脑和云盘连接由用户操作触发。云盘授权及续期会直接访问 Google/Microsoft 的授权服务和文件 API；授权库可能发送其服务运行所需的诊断信息，应用不记录令牌。详见[云盘账号与数据说明](cloud-drives.md#账号与数据)。
