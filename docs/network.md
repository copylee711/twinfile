# 网络位置

支持 FTP、FTPS、SFTP、SMB 2/3 和 WebDAV。添加后可以像本地文件夹一样浏览和操作，两个窗口之间可以复制文件。空闲两分钟自动断开，下次操作会重连。

## SMB

分别填写主机（IP 或域名，不含协议和共享路径）、端口（默认 445）、用户名、密码，以及共享路径。域可以留空。路径的第一段是共享名，例如服务器发布的共享叫 Public，填写 `/Public`；若只打开其中一个目录，填写 `/Public/文档`。路径也接受反斜杠。

暂不支持枚举服务器上的所有共享。不能只填写主机而把共享路径留空或填 `/`；应用会显示缺少共享名的提示。SMB 保存前会真实读取指定目录，权限不足、共享名错误和网络故障均显示为失败，不再误报空目录连接成功。

共享名以服务器实际发布的名字为准，不是服务器磁盘的完整本地路径。需要先在 Windows 或 NAS 上配置共享和访问权限。用户名留空时使用 Guest 访客认证，仅适用于服务器允许访客访问的共享；受保护的共享请填写账户和密码。

## 其他协议

- FTP / FTPS：配置主机、端口、初始路径、用户名和密码，按服务器选择隐式 TLS。
- SFTP：支持密码或私钥。首次连接需要核对主机指纹，以后指纹变化时拒绝连接。
- WebDAV：填写服务器的 WebDAV 路径，并按实际情况启用 HTTPS。

密码经 Android Keystore 加密保存在本机。只有明确使用自签名证书时才选择“信任所有证书”。

云盘不等同于 WebDAV 或 SMB；Google Drive 和 OneDrive 的后续接入方案见 [OAuth 调研](cloud-drives.md)。
