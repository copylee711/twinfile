# 压缩格式与密码

| 格式 | 创建 | 解压 | 创建加密包 | 解压加密包 | 像目录一样浏览 |
|---|---|---|---|---|---|
| ZIP | 是 | 是 | AES-256 | ZipCrypto、AES | 是 |
| 7z | 是 | 是 | 否 | 是 | 否 |
| TAR | 是（仅打包） | 是 | 否 | 不适用 | 否 |
| TAR.GZ / TGZ | 是（创建 .tar.gz） | 是 | 否 | 不适用 | 否 |
| RAR | 否 | 否 | 否 | 否 | 否 |

长按文件或选择多个文件后点“压缩”，选择格式并填写名称；ZIP 可勾选“设置密码”。密码仅用于本次操作，不会保存到设置或日志。AES-256 ZIP 加密内容，文件名仍可见，部分旧版解压工具不支持这种加密方式。

点击 ZIP 可以进入浏览。打开加密 ZIP 或解压加密包时输入密码；密码错误可重新输入，取消会结束任务。7z、TAR、TAR.GZ/TGZ 点击后解压到当前目录，也可用长按菜单“解压到此处/解压 →”（均采用智能解压）。这些解压操作目前针对本地文件，远程压缩包请先复制到本地。

智能解压根据顶层结构决定目录：只有一个顶层文件夹时，直接保留这个文件夹，避免形成 `name/name/` 的额外外壳；有顶层文件或多个顶层项目时，创建以压缩包名称命名的目录，避免文件散落。`.tar.gz` 和 `.tgz` 会正确移除完整后缀。压缩包内原本有意义的嵌套目录不会继续递归扁平化；隐藏文件也参与判断，不会丢弃。目标已存在同名文件或目录时自动编号，不合并或覆盖。解压先写入独立临时目录，完成后才将结果放到目标位置。错误密码、取消、损坏文件或非法路径导致失败时，会清理该次创建的目录。拒绝目录穿越路径和 TAR 符号链接、硬链接、设备等特殊条目。7z 解码的内存使用限制为 64 MiB，超出限制的高字典压缩包会报错，需用较小字典重新压缩或在电脑解压。

ZIP 文件名优先 UTF-8，遇到无效 UTF-8 时回退到 GBK；TAR 使用 UTF-8。压缩保留空文件夹和文件修改时间，不保留 Unix 权限、链接或所有者。压缩输入中的符号链接会明确报错。

实现使用 [Zip4j](https://github.com/srikanth-lingala/zip4j) 和 [Apache Commons Compress](https://commons.apache.org/proper/commons-compress/examples.html)。Commons Compress 支持读取加密 7z，不支持创建加密 7z。
