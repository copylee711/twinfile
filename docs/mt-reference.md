# MT 管理器 2.26.10 功能对照表

在 AVD test_avd（Android 15）上实际操作 MT 2.26.10 时记下的功能和交互，只看功能，没有看代码。TwinFile 用自己的 UI 风格，这里只用来对照功能和操作习惯。

标记：✅ MVP 要做 · 🔜 后续版本 · ❌ 不做（反编译 / APK 编辑 / 和定位无关）

## 主界面

| MT 的功能 | 交互 | TwinFile |
|---|---|---|
| 顶栏 | 显示当前焦点栏的路径，第二行是「文件夹: N 文件: N 已选: N 储存: 已用/总量」 | ✅ |
| 点顶栏路径 | 弹出「跳转」对话框，可以输入或粘贴路径 | ✅ |
| 左右两栏 | 各自独立浏览；在哪一栏操作，焦点就切到哪一栏 | ✅ |
| 列表第一行 `..` | 点一下回到上一级 | ✅ |
| 列表项 | 图标或缩略图、文件名、`yy-MM-dd HH:mm`、大小（文件夹不显示大小） | ✅ |
| 点文件 | 图片进内置看图（标题栏显示尺寸，可以在同一文件夹的图片之间切换，有「x/总数」、勾选、外部打开）；其他文件用打开方式 | ✅ |
| 底栏 | 后退 · 前进 · 新建 · 两栏同步/交换 · 上一级 | ✅ |
| 新建 | 一个输入框，下面是「文件」「文件夹」两个按钮 | ✅ |
| 从底栏上滑 | 拉出底部面板，分「最近」「书签」两个标签页；「最近」里同时有文件夹和文件 | ✅ |

## 选择

- **左右滑动一个文件就能选中它**（MT 的核心手势），选中项高亮，顶栏显示「已选: N」。
- 选择模式的底栏：全选、反选、退出、区间选择（选中两项之间的全部）、更多。
- 「更多」里的批量选择：同一天、同一周、同一月、同一年；按文件时间、按大小、按关键词。✅（时间和关键词放进 MVP，按大小 🔜）

## 长按菜单

复制 → 另一栏、移动 → 另一栏（两栏路径相同时禁用；标了「•」的项长按可以在本栏内操作）、删除、重命名、工具、压缩、属性、分享、打开方式、添加书签。✅

「工具」子菜单：
- 文件分割 / 合并 🔜
- 加密 / 解密 🔜
- 交换文件名（选中 2 个时可用）✅
- 创建软链接 🔜
- 创建快捷方式 🔜
- 导出文件列表 🔜

## 属性和校验

- **属性**：名称、目录、类型、大小（带精确字节数）、修改时间、权限（`-rw-rw----(660)`）、所有者、用户组。✅
- **校验**：MD5、SHA1、SHA256、CRC32，每项都能复制；「粘贴并校验」可以和粘贴的值比对；有大写字母选项。✅

## 右上角菜单

刷新、搜索 🔜、全选、过滤、排序方式、打开终端 ❌、隐藏文件（子菜单）、添加书签、设为首页、交换窗口、设置、退出。✅（除了已标注的）

排序对话框按窗口生效：
- 方式：名称、日期、大小、类型
- 「仅应用于此文件夹」
- 「逆向排序」
- 「管理」（按文件夹的排序规则）

## 侧边抽屉

- **本地**：根目录、内部存储，带容量进度条和「已用 / 可用」。✅
- **工具**：回收站 ✅、已安装应用 ✅、远程管理（手机开 HTTP/FTP 服务让电脑访问）🔜、文本编辑器 🔜、终端 / 插件 / MCP / Activity 记录 ❌。
- **抽屉右上角菜单**：
  - 主题跟随系统
  - 添加网络存储 ✅：FTP，FTPS / SFTP / SMB / WebDav / 对象存储（这几个在 MT 里要 VIP；TwinFile 免费，对象存储 🔜）
  - 添加本地存储
  - 添加网络分组
  - 管理工具分组
- **FTP 表单**：主机、端口（默认 21）、用户名、密码、初始路径、备注、编码（UTF-8）、测试、保存。✅
- **更多工具**：屏幕取色、签名密钥、常用密码、音乐播放器、流媒体播放、Smali、远程 Payload，都不做 ❌。

## 已安装应用

- 「用户应用」和「系统应用」两个标签页，带搜索；每项显示图标、名称、版本、大小、包名。✅
- 点开是详情：包名、版本号、安装包大小、签名状态（V2 等）、目标 SDK 和最低 SDK、数据目录、APK 路径、首次安装、最后更新、UID。✅（「加固状态」❌）
- 按钮：提取安装包；「更多」里有启动、详情（系统设置页）、卸载。✅

## 设置（只记 TwinFile 用得上的）

| 分组 | 项目 | TwinFile |
|---|---|---|
| 启动 | Root / Shizuku 模式、左右窗口的启动路径（首页） | 首页 ✅，Shizuku 🔜 |
| 外观 | 主题色、文件列表大小、文件名最大行数、时间格式（隐藏秒数、精简年份） | 主题 / 深色 🔜，列表密度和时间格式 ✅ |
| 常规 | 复制 / 解压时保留文件时间、文件菜单排序 | 保留时间 ✅ |
| 回收站 | 启用回收站、默认移到回收站、自动清理（N 天）、不进回收站时显示红色警告 | ✅ |
| 书签和底栏 | 抽屉里显示书签、新书签加到顶部、底栏下边距（避免和全面屏手势冲突） | ✅ |
| 外置存储 | 用 Document API 访问 U 盘 / SD 卡、是否加载缩略图 | 🔜（MVP 先用文件路径） |
| 网络存储 | 加载缩略图、仅 Wi-Fi 下加载、图片超过 10 MB 不加载、超过 10 秒取消 | ✅ |

## 和原方案的差异（已经改进计划）

1. 多选：不用「长按进入多选」，改成 **左右滑动选中**，长按弹出操作菜单，和 MT 的习惯一致。
2. 书签和最近访问：放进 **从底栏上滑拉出的面板**；抽屉里也显示一份书签。
3. 属性的校验加上 SHA1、CRC32 和「粘贴并校验」。
4. 选择模式加上区间选择和按时间 / 关键词批量选。
