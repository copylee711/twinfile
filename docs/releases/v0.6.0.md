# v0.6.0

## 最近文件与打开记录

- 底部右侧新增「最近文件」入口，在当前栏原位显示，保留另一栏目录，聚合显示本地公共存储中最近新增或修改的文件。
- 优先读取系统索引，再补查未被索引的文件，例如下载目录中的文档和图片。最多显示最近 500 项，扫描可停止或刷新；不扫描远端、Android/data、Android/obb、回收站或解压临时目录。
- 新增「最近打开」视图，独立保存最多 200 条在 TwinFile 中打开的本机文件记录。可清空记录，或在设置中关闭后续记录。
- 最近文件长按菜单增加「定位所在位置」，打开真实目录并高亮目标；复制、移动等操作沿用原有文件操作流程。
- 系统未收录的文件按修改时间排序；文件是否可见仍受存储访问权限和隐藏文件设置影响。

- 条目统一文件名、时间与大小、所在目录的紧凑布局；扫描范围仅首次短暂提示，不占据常驻列表空间。

## 导航与操作

- 默认恢复各栏已访问目录的滚动位置，返回上级时保留原浏览位置；可在设置关闭。
- 设置新增「固定上级目录入口」，默认开启，「..」入口固定在列表顶部，便于滚动后返回上级。
- 侧栏顶部新增横向图标快捷入口，包含下载、文档、相机、图片、音乐、视频及自定义书签，支持横向滚动；长按六个预设图标可自定义目录或恢复默认。
- 文件操作菜单缩短解压标签，并根据可用宽度和字体大小切换一列或两列，避免操作名称生硬换行。解压仍采用智能解压规则。
- 云盘入口改用云朵图标，与网络位置区分。

上述记录仅保存在本机；本次未新增权限。
