TwinFile 第一个版本。

**主要功能**
- 双栏文件管理：左右滑动选中文件，按住拖动连续选择；在两栏之间复制、移动，同名冲突可以选择怎么处理
- 应用自己的回收站，删错了可以恢复
- 直接浏览 ZIP，支持解压、压缩；内置图片和文本查看器
- 已安装应用：查看应用信息，提取 APK（分包应用打成 .apks）
- 网络位置全部免费：FTP、FTPS、SFTP、SMB、WebDAV
- 配合 SyncBoard 电脑端，在双栏里直接管理电脑上的文件
- 7 种主题色，支持深色模式

**安装**
- 支持 Android 8.0 及以上
- 首次打开需要授予「所有文件访问权限」

**校验**：下载后可以用 SHA256SUMS.txt 核对安装包的哈希值。
