# v0.5.0

## 云盘

- 新增 Google Drive / OneDrive 原生授权客户端，接入双栏浏览、上传、下载、新建、重命名、移动和云端回收站。
- Google Drive 使用完整云盘权限，已配置正式签名的 Android 客户端；OneDrive 的应用尚未注册，登录入口暂不启用。
- 云端文件按对象 ID 操作，Google Drive 的同名文件可以独立选择、复制或删除。
- 读取完整分页；授权失效、权限不足和限流明确提示，避免误报空目录。
- Google 文档、表格、幻灯片和绘图可以导出为 PDF；暂不支持共享云端硬盘和跨 drive 快捷方式。
- 上传采用本机暂存与有界分块；源读取失败或取消时不提交残缺的缓存文件。移除账号时停用旧来源并清理本机缓存。

真实账号登录和云端文件往返仍需账号联调。当前验证覆盖模拟 API、分块协议、跨来源传输和失败清理，不代表已完成真实 Google/Microsoft 账号验收。
