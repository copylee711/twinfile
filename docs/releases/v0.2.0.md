这一版主要根据真机使用反馈改进。

**操作**
- 碰一下哪栏就切到哪栏，不用再点文件夹进出
- 标题栏改成可点击的路径，点哪一级就跳到哪一级；长按仍可输入路径
- 第一次滑动进入多选时，那一行会跟手滑动并轻微振动
- 单栏模式变成真正的单栏：复制/剪切后到任意文件夹粘贴
- 抽屉里的书签移到网络位置下面，并且可以折叠

**打开文件**
- 新的「打开方式」面板：可以记住每种文件的默认应用，或者按文本、图片等类型打开
- 在其他应用的打开方式或分享菜单里选「定位所在位置」，直接跳到文件所在位置
- Markdown 预览
- PDF、Word、Excel、PPT、代码、脚本、电子书各有图标

**新功能**
- 通过 Shizuku 或 Root 访问 Android/data、obb，Root 还能浏览整个系统
- 启动时检查更新，可以直接下载安装、以后再说或不再检查；设置里有 GitHub 发布页入口

**修复**
- 窄栏里文件大小的单位被截掉
- 高刷新率屏幕上只跑 60 Hz（现在会请求最高刷新率）

**其他**
- 新图标

**安装**：支持 Android 8.0 及以上。从 0.1.0 升级可以直接覆盖安装。

**校验**：下载后可以用 SHA256SUMS.txt 核对安装包的哈希值。
