# v0.5.1

## 智能解压

- 压缩包只有一个顶层文件夹时，直接保留该文件夹，避免额外生成 `name/name/` 结构。
- 存在顶层文件或多个顶层项目时，以压缩包名称创建目录，避免文件散落在目标位置。
- 支持 ZIP、7z、TAR、TAR.GZ/TGZ，保留空目录、隐藏条目和包内原有嵌套结构。
- 结果与现有文件或目录同名时自动编号，不合并或覆盖。密码错误、取消、损坏和非法路径仍清理本次临时内容。
