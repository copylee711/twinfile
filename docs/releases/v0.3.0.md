**配合 SyncBoard 手机 App**
- 手机上装了 SyncBoard（0.4.1 及以上）时，在「电脑」页点「在 SyncBoard 里允许」，就能直接使用它已连接的电脑浏览、复制、管理文件，不用再配对一次
- 「设置 → 高级访问」新增 SyncBoard 选项：借 SyncBoard 手机服务访问 Android/data、obb，不需要 Shizuku 或 Root
- 授权只需一次，可以在 SyncBoard 的 设置 → 已授权的应用 里撤销

**改进**
- 多选后的底栏改为 复制、移动（单栏时为剪切）、删除、更多操作、选择、取消，每个按钮都有文字说明；全选、反选、选中两项之间的全部等收进「选择」菜单
- 打开文件时默认交给系统选择；在「打开方式」里勾选过默认应用的类型会直接用该应用打开
- 文本和 Markdown 可以直接编辑保存，保持原来的编码（UTF-8 / GBK）和换行符
- 书签面板的「最近」「书签」可以左右滑动切换，面板打开时不会再误触侧边栏
- 存储空间进度条去掉了末尾的小圆点

**校验**：下载后可以用 SHA256SUMS.txt 核对安装包的哈希值。
