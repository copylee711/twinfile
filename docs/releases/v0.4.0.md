# v0.4.0

## 压缩与解压

- ZIP 支持输入密码后解压和浏览，兼容 ZipCrypto 与 AES 加密。
- 创建压缩包时可选择 ZIP、7z、TAR 或 TAR.GZ；ZIP 可以设置 AES-256 密码。
- 新增 7z、TAR、TAR.GZ/TGZ 解压，支持加密 7z（包括加密文件名）。
- 密码错误可重新输入；取消、损坏文件或非法路径导致失败时清理本次解压目录。
- ZIP 文件名保留 UTF-8/GBK 兼容，拒绝目录穿越；TAR 不提取链接和特殊文件。

7z 暂不支持创建加密包；RAR 暂未支持。ZIP 加密内容，文件名仍然可见。

## SMB

- 修复共享路径留空时未经实际连接就显示“连接成功、空文件夹”的问题。
- 明确要求填写共享路径（如 `/Public`），并在保存前实际读取该目录。
- 支持反斜杠共享路径，连接失败时释放连接资源。
- 留空用户名时使用访客认证，修复部分 SMB3 服务器上空会话密钥导致的认证异常。

目前仍不支持自动枚举服务器上的共享名。
