TwinFile 隐私政策

生效及更新日期：2026 年 10 月 30 日

TwinFile 是由 Copy Lee（GitHub：copylee711）维护的开源 Android 文件管理器。本政策说明官方发行版如何处理数据，适用于本地文件、网络位置、电脑配对和可选云盘功能。隐私联系邮箱：copylee711@gmail.com。

1. 数据处理方式

TwinFile 没有用于接收用户文件或云盘数据的自有后端，不要求创建 TwinFile 账号，不内置广告或应用内统计服务。文件操作在你的设备上执行，或直接访问你选择的服务器与云盘。开发者不会因你使用应用而自动收到文件内容、文件列表或云盘访问令牌。

2. 访问哪些数据，以及为什么访问

  • 本地文件：在你授予存储权限后，读取目录、名称、大小、修改时间及所操作文件的内容，用于浏览、预览、复制、移动、删除、压缩、解压和校验。解压密码用于本次操作，不持久保存。
  • 网络位置和电脑：处理你填写的地址、用户名、连接凭据、配对信息及你浏览或操作的远端文件，用于连接你选择的 FTP、FTPS、SFTP、SMB、WebDAV 服务或 SyncBoard 电脑。
  • Google Drive：在你主动连接并授权后，访问账号邮箱、显示名称、账号标识，及“我的云端硬盘”中文件的 ID、名称、类型、大小、时间、目录关系和你选择读取或传输的文件内容。账号信息用于区分账号；文件数据用于双栏浏览、预览、上传、下载、新建、重命名、移动和移入云端回收站。Google 原生文档可以导出为 PDF。
  • 权限范围：Google Drive 使用 https://www.googleapis.com/auth/drive。完整文件管理需要访问既有目录和文件；仅限应用创建或选取文件的 drive.file 无法提供全盘浏览与整理。你可以不连接 Google Drive，继续使用本地功能。
  • OneDrive：完成应用注册并开放后，通过 Microsoft 原生授权请求 Files.ReadWrite，处理账号标识、显示信息、默认 OneDrive 的文件元数据及所操作的文件内容，目的与上述文件管理功能相同。当前正式版本尚未开放 OneDrive 登录。
  • 设备权限：应用列表用于展示已安装应用和提取 APK；相机用于扫描电脑配对二维码；通知与前台服务用于长任务进度；安装权限用于将 APK 交给系统安装器。授权 SDK 可使用 NFC 安全密钥。权限由 Android 和服务商管理。

3. 本机保存与保留时间

设置、书签、历史位置和连接配置保存在应用目录中。网络密码和云盘账号元数据使用 Android Keystore 支持的加密机制保存。Google 和 Microsoft 的授权凭据由平台及各自 SDK 管理；TwinFile 不把访问令牌写入普通账号 JSON 或日志，也不获取你的 Google/Microsoft 密码。

上传暂存、预览和外部打开文件可能在设备上生成缓存；缓存文件本身不额外逐文件加密，依赖 Android 应用私有存储及设备保护。缓存可能保留到任务清理、账号移除、系统缓存清理或你清除应用数据时；应用不承诺固定的自动清理期限。保存到你指定目录的文件、导出文件、接收方副本及本地回收站内容可能继续保留，须由你管理。应用关闭 Android 自动备份。

4. 传输、共享与第三方

云盘文件通过 HTTPS 在设备与 Google/Microsoft 的文件接口或其预授权文件地址之间传输，不经 TwinFile 自有服务器。如果你主动将云盘文件复制到网络位置、电脑、另一云盘或外部应用，该目标会收到你选择的文件；网络协议的加密能力取决于你选择的协议和服务配置，FTP 或未加密 HTTP 等连接可能不加密传输。

开启自动更新检查或手动检查更新时，应用会访问 GitHub；下载更新时访问 GitHub 发布资源。Google/Microsoft 授权与 SDK 会与各自服务通信，服务商可能处理网络地址、设备信息及提供服务所需的诊断信息。其数据处理另受各自隐私政策约束：Google、Microsoft、GitHub。

5. Google 用户数据的有限使用

TwinFile 仅将 Google 用户数据用于提供你能看到并主动使用的文件管理功能，不出售用户数据，不用于广告、用户画像、信用判断或训练通用人工智能模型。开发者不会读取你的 Google 文件，应用不向开发者自动回传这些文件。向其他目标的文件传输只在你选择相应操作时发生。

TwinFile's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. 撤销授权与删除数据

  • 在 TwinFile 的“云盘”页面移除账号，会停用该账号的来源、删除本机保存的账号元数据并尝试清理对应缓存，同时尝试撤销或移除应用授权。离线或服务商失败时，远程撤权可能未完成。
  • 你可以随时在 Google 账号的第三方连接页面或 Microsoft 账号/组织的应用权限页面撤销访问。此操作不删除手机上的系统账号。
  • 通过 Android“应用 → TwinFile → 存储”清除数据，或卸载应用，可以清理其私有数据；保存在共享存储、外部应用或远端的文件不会因此被删除。授权 SDK 的缓存也可能需要在服务商处撤权。
  • 云端删除进入服务商回收站，恢复方式与保留期由服务商决定。撤销授权和卸载应用均不等同于删除云端文件。

7. 支持请求与网站访问

当你主动发送邮件或提交问题时，开发者会收到你提供的内容，用于答复和排查。GitHub Issues 是公开的，请先移除隐私信息；如需删除开发者持有的支持资料，请通过上述邮箱联系，依法需要保留的内容除外。本应用介绍网站不使用应用文件或云盘令牌；网站托管和安全服务可能记录访问地址、时间、浏览器及 IP 等网络日志，参见开发者网站隐私政策。

8. 政策变更与联系

本页将注明更新日期。如未来改变 Google 用户数据的用途，应用将在实施新用途前更新披露并重新请求所需同意。关于本政策、账号数据或删除请求，请联系 copylee711@gmail.com。
